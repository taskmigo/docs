A `v0/component` packages a component tree once so any Page can import and render it. Declare the values each Page may provide in `spec.props`, then read those values from `spec.template` through `{{ props.<name> }}`.

A Component may import other Components. Every reusable Component used in `spec.template` must appear in `imports`; built-in components such as `Stack` and `Typography` do not require imports.

```yaml
apiVersion: v0
kind: component

metadata:
  name: header

spec:
  props:
    title:
      type: string
      required: true
    showDescription:
      type: boolean
      required: false
      default: true
    items:
      type: array
      required: false
      default: []

  template:
    component: Stack
    children:
      - component: Typography
        props:
          variant: h1
        children: '{{ props.title }}'
```

Prop names are case-sensitive. A `default` value must match its declared `type`. An `array` may contain strings, numbers, and booleans; nested arrays and objects are not supported. Values in `spec.template` may use the full Taskmigo Expression syntax and access declared props through `props.<name>`. See [Expressions](/versions/v0/expressions#use-context-values) for syntax and context.

Every node in `spec.template` must satisfy the selected component's contract.

## Use the Component in a Page

Import the Component by resource identity, then use its name as the node's `component` value. The node's `props` are validated against `spec.props`.

```yaml
apiVersion: v0
kind: page

metadata:
  name: dashboard

imports:
  - component/header

spec:
  meta:
    title: Dashboard
    description: Account overview

  body:
    - component: header
      props:
        title: Dashboard
        showDescription: false
```

Any number of Pages may import the same Component. Each Page supplies its own props while every use renders the same template.

An importing Page is invalid when it omits a required prop, supplies an undeclared prop, or provides a value that does not match the declared prop type.
