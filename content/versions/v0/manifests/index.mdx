Manifests describe the resources that make up a Taskmigo system. Start with the outcome you want,
then open the matching reference for a complete example, its `spec` fields, and validation rules.

| I want to…                                       | Use this manifest                                    |
| ------------------------------------------------ | ---------------------------------------------------- |
| Compose applications and set shared branding     | [Site](/versions/v0/manifests/v0-site)               |
| Group pages under a path and assign their routes | [Application](/versions/v0/manifests/v0-application) |
| Build an interface from registered components    | [Page](/versions/v0/manifests/v0-page)               |
| Reuse one typed component tree across Pages      | [Component](/versions/v0/manifests/v0-component)     |
| Add translated messages for a locale             | [Translation](/versions/v0/manifests/v0-translation) |

## Manifest types

<Cards>
  <Card href="/versions/v0/manifests/v0-site" title="Site">
    Start the resource graph, expose applications, and define shared branding.
  </Card>
  <Card href="/versions/v0/manifests/v0-application" title="Application">

  </Card>
  <Card href="/versions/v0/manifests/v0-page" title="Page">
    Build a user interface from registered components.
  </Card>
  <Card href="/versions/v0/manifests/v0-component" title="Component">

  </Card>
  <Card href="/versions/v0/manifests/v0-translation" title="Translation">

  </Card>
</Cards>
