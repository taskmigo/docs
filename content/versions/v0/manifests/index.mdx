Manifests describe the resources that make up a Taskmigo system. Choose the outcome below to open its complete example, `spec` fields, and validation rules.

<Cards>
  <Card href='/versions/v0/manifests/v0-site' title='Compose applications'>
    Use a Site to start the resource graph, expose applications, and define shared branding.
  </Card>
  <Card href='/versions/v0/manifests/v0-application' title='Route Pages'>
    Use an Application to group Pages under one application path and assign their routes.
  </Card>
  <Card href='/versions/v0/manifests/v0-page' title='Build an interface'>
    Use a Page to create a user interface from registered Components and expose Workflows.
  </Card>
  <Card href='/versions/v0/manifests/v0-component' title='Reuse interface'>
    Use a Component to reuse one typed component tree across any number of Pages or interactive Workflow steps.
  </Card>
  <Card href='/versions/v0/manifests/v0-translation' title='Translate content'>
    Use a Translation resource to add messages to a locale catalog.
  </Card>
  <Card href='/versions/v0/manifests/v0-workflow' title='Run a Workflow'>
    Define durable execution with actions, interactive steps, conditional navigation, and version pinning.
  </Card>
</Cards>
