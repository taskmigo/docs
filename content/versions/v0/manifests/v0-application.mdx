---
title: Application
description: Group Pages under a shared URL path.
---

import { TypeTable } from 'fumadocs-ui/components/type-table';

```yaml
apiVersion: v0
kind: application
metadata:
  name: home
imports:
  - page/index
spec:
  icon: https://example.com/images/home.png
  label: '{{ Trans "applications.home.label" }}'
  description: '{{ Trans "applications.home.description" }}'
  path: /home
  routes:
    - page: index
      path: /
```

This exposes the imported Page `index` at `<host>/home/`.

## Paths and routes

| Application path | Page path   | Result                 |
| ---------------- | ----------- | ---------------------- |
| `/home`          | `/`         | `<host>/home/`         |
| `/home`          | `/settings` | `<host>/home/settings` |

`/` is the Application index. Every routed Page must appear in `imports`; importing one alone does not expose a route. `imports` and `spec.routes` cannot be empty, and route paths must be unique.

See [Resource model](/versions/v0/resources#references) for reference rules.
