---
title: Taskmigo
description: Build a self-hosted low-code application from declarative resources.
---

Taskmigo is an open-source, self-hosted low-code application platform. YAML resources define a site's UI, behavior, and data model.

Resources are authored through the Taskmigo UI or API. YAML remains canonical; Git is not part of the authoring or version-control model.

## Start here

<Cards>
  <Card
    title='Start a Site'
    href='/versions/v0/manifests/v0-site'
    description='Create the entry point for your application and choose which Applications it exposes.'
  />
</Cards>

A Site starts the resource graph. It exposes Applications; each Application routes Pages; Pages compose registered UI Components. Add Translation resources when a Page needs localized content.

<Callout title='Workflow is currently an RFC' type='info'>
  [`v0/workflow`](/versions/v0/manifests/v0-workflow) is documented end to end for design review, including resource relationships, Expressions, durable execution, conditional navigation, UI steps, and version pinning. It is not a supported manifest contract yet. See [Product status](/versions/v0/status).
</Callout>
