# Taskmigo

Taskmigo is an open-source, self-hosted low-code application platform. A site is described by YAML resources that define its UI, behavior, and data model.

YAML is the canonical source. Users author resources through the Taskmigo UI and API; Git is not part of the authoring or version-control model.
