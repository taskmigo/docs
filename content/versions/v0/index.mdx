---
title: Taskmigo
description: Define application UI as versioned resources and serve validated immutable runtime snapshots.
---

Taskmigo lets teams describe an application with versioned YAML resources. The backend validates the complete Site, compiles an immutable snapshot, and serves that snapshot without rebuilding the application from mutable manifests on every request.

```mermaid
flowchart LR
  author["Author YAML Resources"] --> validate["Resolve + validate"]
  validate --> snapshot["Immutable Site snapshot"]
  snapshot --> binding["Browser runtime binding"]
  binding --> ui["Rendered application"]
```
