---
title: Expressions
description: Put dynamic text or values into fields that accept an Expression.
---

Use an Expression when a field needs a value that Taskmigo can resolve while it evaluates the manifest: translated text, the current manifest identity, runtime values, or Workflow execution state. The language follows Go [`text/template`](https://pkg.go.dev/text/template) syntax and semantics, restricted to the context values and functions documented for each field.

## Start here

Write an Expression between `{{` and `}}`. Quote the complete YAML value. Taskmigo does not allow arbitrary Go code, custom functions, I/O, or side effects.

```yaml
spec:
  label: '{{ Trans "applications.home.label" }}'
```

In this example:

- `'...'` is the YAML string.
- `{{ ... }}` is the Expression.
- `Trans` is a global function.

## Translate a message

Use `Trans` with a catalog key. Additional values fill the message placeholders.

```yaml
description: '{{ Trans "applications.home.description" }}'
```

For catalog structure, placeholders, fallbacks, and errors, see [Translation](/versions/v0/manuals/manifests/v0-translation#trans).

## Translate a quantity

Use `TransN` when the catalog message changes for a quantity.

```yaml
description: '{{ TransN "cart.items" 3 }}'
```

The second argument is the count. Taskmigo selects the locale's plural form. See [Translation](/versions/v0/manuals/manifests/v0-translation#transn) for the complete rule.

## Use context values

Context values are available only where the field contract exposes them.

| Value               | Available in              | Returns                                                     |
| ------------------- | ------------------------- | ----------------------------------------------------------- |
| `.Runtime.Hostname` | Any Expression            | Hostname at evaluation time                                 |
| `.This.kind`        | Any Expression            | Current manifest kind                                       |
| `.This.name`        | Any Expression            | Current manifest name                                       |
| `.This.version`     | Any Expression            | Current manifest version                                    |
| `.This.revision`    | Any Expression            | Current manifest revision                                   |
| `props.<name>`      | Component `spec.template` | A prop passed to that Component                             |
| `input.<name>`      | Workflow execution        | Input captured when the execution started                   |
| `steps.<id>.output` | Workflow execution        | Persisted output of a completed or continued step           |
| `steps.<id>.status` | Workflow execution        | Persisted runtime status of the referenced step             |
| `step.input`        | Current Workflow step     | Input resolved for the step currently being evaluated       |
| `step.output`       | Workflow navigation       | Current step output used to choose the next navigation edge |

Workflow Expressions read persisted execution state from the pinned Workflow revision and Site snapshot. See [Workflow](/versions/v0/manuals/manifests/v0-workflow#expressions-and-data-flow) for field-specific availability.

## Use built-in functions

_Example values: the prop names below are illustrative. A Component can access only props declared in its own `spec.props`._

| Need                       | Functions                          | Example                                                  |
| -------------------------- | ---------------------------------- | -------------------------------------------------------- |
| Combine boolean conditions | `and`, `or`, `not`                 | `{{ if and props.enabled props.visible }}Shown{{ end }}` |
| Compare values             | `eq`, `ne`, `lt`, `le`, `gt`, `ge` | `{{ if eq props.variant "primary" }}Primary{{ end }}`    |
| Count a value              | `len`                              | `{{ len props.items }}`                                  |
| Select a value             | `index`                            | `{{ index props.items 0 }}`                              |
| Select a range             | `slice`                            | `{{ slice props.items 0 2 }}`                            |
| Format a value             | `printf`                           | `{{ printf "Hello, %s" props.name }}`                    |

## More Expression syntax

Expressions can also use pipelines, local variables, conditions, and iteration.

| Need                                 | Syntax example                                           |
| ------------------------------------ | -------------------------------------------------------- |
| Pass a result to another function    | `{{ props.title \| printf "%s" }}`                       |
| Store and reuse a value              | `{{ $title := props.title }}{{ $title }}`                |
| Render only when a condition matches | `{{ if props.active }}Active{{ else }}Inactive{{ end }}` |
| Iterate a value                      | `{{ range props.items }}{{ . }}{{ end }}`                |

Names and paths are case-sensitive.

## Before you save

1. Quote the YAML value when it includes Expression syntax.
2. Use only functions and context values available in that field.
3. Ensure that the evaluated result matches the field's required type.
