## Known limitations and open decisions

- Multi-tenancy is not available.
- Expressions execute only in the Taskmigo backend. Frontend/browser Expression evaluation and frontend-only context variables are not defined in v0.
- A browser application instance is defined to keep one runtime binding across client-side navigation and normally replace it on full reload. The concrete binding token/lease representation, maximum lifetime, expiry/revocation mechanism, and renderer compatibility protocol are not finalized.
- Locale is captured as presentation context so one tab cannot silently change language because another tab updates the profile default. The transport used for an explicit in-tab language change is not finalized.
- Additional presentation fields such as timezone or SSR theme are not yet defined as runtime-binding fields. Security-sensitive mutable state is explicitly not assumed to be pinned with presentation context.
- The SSR serving API must support a self-contained render result in one backend round trip on the happy path, but its endpoint and request/response schema are not finalized.
- Page UI currently includes only [`Stack`](/versions/v0/manuals/ui-components/stack) and [`Typography`](/versions/v0/manuals/ui-components/typography), with their minimum props.
- Missing-translation-key behavior and translation override precedence are not defined.
- Snapshot artifact encoding, cache strategy, and retention are not finalized.
- Public revision-tag API paths, authorization, and deletion policy are not defined.
- The API and management surface used to attach registered Policies to Roles are not defined.
