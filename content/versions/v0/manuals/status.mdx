“Defined” means the documentation defines the intended public contract; it does not independently guarantee that every contract is implemented. RFC capabilities are explicitly unavailable in the current runtime.

## Known limitations and open decisions

- Multi-tenancy is not available.
- Expressions execute only in the Taskmigo backend. Frontend/browser Expression evaluation and frontend-only context variables are not defined in v0.
- Page UI currently includes only [`Stack`](/versions/v0/manuals/ui-components/stack) and [`Typography`](/versions/v0/manuals/ui-components/typography), with their minimum props.
- Missing-translation-key behavior and translation override precedence are not defined.
- Snapshot artifact encoding, cache strategy, and retention are not finalized.
- Public revision-tag API paths, authorization, and deletion policy are not defined.
- The API and management surface used to attach registered Policies to Roles are not defined.
