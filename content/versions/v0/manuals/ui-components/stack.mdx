---
title: Stack
description: Group React nodes in a Page component tree.
---

import { TypeTable } from 'fumadocs-ui/components/type-table';

Use `Stack` to group text and nested components while preserving their source order.

```yaml
component: Stack
props:
  data-component-id: hero
children:
  - component: Typography
    props:
      variant: h1
    children: Hello World
  - component: Typography
    props:
      variant: p
    children: '{{ Trans "pages.index.introduction" }}'
```
