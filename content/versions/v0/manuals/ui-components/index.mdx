---
title: UI Components
description: Choose a built-in component for a Page or reusable Component tree.
---

Built-in component names and props are case-sensitive. They can be used directly without an `imports` entry.

| Component                                                   | Use it to…                                            | Children                                      |
| ----------------------------------------------------------- | ----------------------------------------------------- | --------------------------------------------- |
| [Stack](/versions/v0/manuals/ui-components/stack)           | Group content and preserve source order.              | Text, component nodes, or an ordered mixture. |
| [Typography](/versions/v0/manuals/ui-components/typography) | Render a semantic heading, paragraph, or inline text. | String only.                                  |

For the common node shape and reusable Component behavior, see [Page component nodes](/versions/v0/manuals/manifests/v0-page#component-nodes) and [Component](/versions/v0/manuals/manifests/v0-component).
