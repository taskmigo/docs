## Quick start

```yaml
apiVersion: v0
kind: translation
metadata:
  name: english-applications
spec:
  locale: en
  content:
    applications:
      home:
        label: Home
        welcome: Welcome, %s!
```

```yaml
label: '${Trans("applications.home.label")}'
description: '${Trans("applications.home.welcome", User.Name)}'
```

_`User` is illustrative context data, not a global Taskmigo value._

Translation Resources are selected by locale; they are not imported.

Nested keys form dotted lookup paths. Multiple Translation Resources with the same normalized locale merge into one effective catalog when their final message paths do not conflict.

## Runtime locale

`Trans` and `TransN` use the locale captured by the current browser [runtime binding](/versions/v0/manuals/runtime#browser-runtime-binding). They do not reread the mutable user-profile language on every navigation.

A profile-language change in another tab therefore cannot mix languages inside an already-running tab. The full lifecycle belongs to [Runtime lifecycle](/versions/v0/manuals/runtime).

## `Trans`

```text
Trans("key"[, value...])
```

Additional values fill message placeholders from left to right:

```yaml
orders:
  summary: Order %s belongs to %s.

${Trans("orders.summary", Order.Number, User.Name)}
```

Missing or incompatible placeholder values cause a runtime error.

## `TransN`

`TransN` selects a plural form using the runtime binding locale's [Unicode CLDR plural rules](https://cldr.unicode.org/index/cldr-spec/plural-rules).

```text
TransN("key", count[, value...])
```

```yaml
items:
  count:
    one: You have %d item, %s.
    other: You have %d items, %s.

${TransN("items.count", Cart.Count, User.Name)}
```

Plural dictionaries may use CLDR categories `zero`, `one`, `two`, `few`, `many`, and `other`. Always define `other`.

<Steps>
  <Step>

### Resolve the locale

Use the runtime binding locale. If its catalog is unavailable, use the configured global fallback locale.

  </Step>
  <Step>

### Select the plural form

Evaluate the count with the locale's CLDR rules. Use `other` when the selected category is absent.

  </Step>
  <Step>

### Fill placeholders

Apply the count first, then additional values from left to right.

  </Step>
</Steps>

## Merge catalogs

| Conflict                                                           | Result                                         |
| ------------------------------------------------------------------ | ---------------------------------------------- |
| Different dictionary/message paths                                 | Merge recursively.                             |
| Two Resources define the same final message path                   | Reject, even when both messages are identical. |
| One Resource defines a message where another requires a dictionary | Reject.                                        |

Merge results never depend on Resource load order. A merge diagnostic identifies the locale, conflicting path, and both source Resources.

## Errors and fallbacks

| Condition                                      | Result                                     |
| ---------------------------------------------- | ------------------------------------------ |
| `TransN` receives a non-numeric count          | `[invalid_plural_count:key]`               |
| Selected plural category is missing            | Use `other`.                               |
| Selected category and `other` are missing      | `[untranslated_form:key]`                  |
| Runtime binding locale has no catalog          | Use the configured global fallback locale. |
| Message receives too few values                | Runtime error.                             |
| Value is incompatible with its formatting verb | `[translation_format_error:key]`           |

Missing-key behavior remains open. See [Product status](/versions/v0/manuals/status#known-limitations-and-open-decisions).
