## Quick start

```yaml
apiVersion: v0
kind: translation
metadata:
  name: english-applications
spec:
  locale: en
  content:
    applications:
      home:
        label: Home
        welcome: Welcome, %s!
```

```yaml
label: '${Trans("applications.home.label")}'
description: '${Trans("applications.home.welcome", User.Name)}'
```

_`User` is illustrative context data, not a global Taskmigo value._

Translation resources are selected by locale and are not imported. See [Reference ability](/versions/v0/manuals/resources#reference-ability).

Resources with the same normalized locale merge into one effective catalog. Nested keys form dotted lookup paths.

## Runtime locale

A browser application instance uses the locale captured by its [runtime binding](/versions/v0/manuals/runtime#one-browser-app-one-runtime-binding). `Trans` and `TransN` use that locale for the lifetime of the binding instead of rereading the user's mutable profile language on every navigation.

This keeps one tab internally consistent. For example, if Tab A is already rendered in Japanese and Tab B changes the user's profile language to English, Tab A continues rendering newly navigated Pages in Japanese. A full reload can bootstrap from the newer profile default, and an explicit language change in Tab A can replace that tab's presentation binding consistently.

## Trans

```text
Trans("key"[, value...])
```

Values fill formatting placeholders from left to right:

```yaml
orders:
  summary: Order %s belongs to %s.

${Trans("orders.summary", Order.Number, User.Name)}
```

Missing or incompatible placeholder values cause a runtime error.

## TransN

`TransN` selects a plural form using the runtime binding locale's [Unicode CLDR plural rules](https://cldr.unicode.org/index/cldr-spec/plural-rules).

```text
TransN("key", count[, value...])
```

```yaml
items:
  count:
    one: You have %d item, %s.
    other: You have %d items, %s.

${TransN("items.count", Cart.Count, User.Name)}
```

Plural objects use CLDR categories `zero`, `one`, `two`, `few`, `many`, and `other`. Always define `other`.

<Steps>
  <Step>

### Resolve the locale

Use the locale captured by the current runtime binding. If its catalog is unavailable, use the configured global fallback.

  </Step>
  <Step>

### Select the plural form

Evaluate the count with the locale's CLDR rules. Fall back to `other` when the selected category is absent.

  </Step>
  <Step>

### Fill placeholders

Apply the count first, then additional values from left to right.

  </Step>
</Steps>

## Merge catalogs

| Conflict                              | Result                                    |
| ------------------------------------- | ----------------------------------------- |
| Different object paths                | Merge recursively.                        |
| Arrays or non-object values           | Keep as final values; do not concatenate. |
| Two resources define the same path    | Reject, even when values match.           |
| An object and non-object share a path | Reject.                                   |

Merge results never depend on load order. Errors identify the locale, path, and both source manifests.

## Errors and fallbacks

| Condition                                      | Result                                     |
| ---------------------------------------------- | ------------------------------------------ |
| `TransN` receives a non-numeric count          | `[invalid_plural_count:key]`               |
| Selected category is missing                   | Use `other`.                               |
| Selected category and `other` are missing      | `[untranslated_form:key]`                  |
| Runtime binding locale is unavailable          | Use the configured global fallback locale. |
| Message receives too few values                | Runtime error.                             |
| Value is incompatible with its formatting verb | `[translation_format_error:key]`           |

Missing-key behavior is not yet defined. See [Product status](/versions/v0/manuals/status#known-limitations-and-open-decisions).
