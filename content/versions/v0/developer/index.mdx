This section is for engineers building Taskmigo: new team members learning the system, contributors implementing a bounded change, and architects reviewing cross-cutting behavior.

<Callout title='Contract and implementation status' type='info'>
  Manuals define the public product contract. Developer pages translate that contract into engineering boundaries and
  required invariants. Policy and Workflow remain RFCs; implementation recommendations and open decisions are labeled
  explicitly.
</Callout>

## Reading rule

When a Developer page conflicts with a Manual, the Manual is the public contract. Resolve the mismatch in the same change instead of allowing implementation documentation to become a second contract.
