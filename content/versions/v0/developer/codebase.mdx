`console/src/main/java/com/taskmigo/console/` is the package root used by the target design. A capability exposes only intentional cross-module contracts from its root; implementation lives below `internal`.

## Public ports that other code may depend on

| Port/type | Responsibility |
| --- | --- |
| `ManifestContract` | Validate and normalize one `(apiVersion, kind)` Resource revision. |
| `SnapshotContributor` | Add deterministic capability-owned artifacts to a Site snapshot. |
| `ActiveSiteSnapshotProvider` | Acquire the current snapshot during bootstrap or an exact retained snapshot for a validated binding. |
| `RuntimeBindingService` | Bootstrap, validate, and encode the opaque application-instance binding. |
| `RuntimeRenderService` | Resolve one path into a self-contained render model using an already validated binding. |
| `SiteSnapshotActivated` | Notify observers after the durable activation boundary. |

Keep repositories, JPA entities, compiler internals, controllers, and FreeMarker implementation types out of the public Resource package.

## Where new code belongs

| Code | Target location |
| --- | --- |
| Use-case orchestration and transaction boundary | `<capability>/internal/application/<use-case>` |
| Domain value, parser, compiler algorithm, invariant | `<capability>/internal/domain/<area>` |
| JPA/JDBC adapter | `<capability>/internal/persistence/<area>` |
| Controller/DTO/Problem Details mapping | `<capability>/internal/web/<area>` |
| Framework bean composition | `<capability>/internal/configuration` |
| Cross-module port/event | `<capability>` public root |
| Flyway migration | `console/src/main/resources/db/migration` |
| Capability tests | matching package below `src/test/java` |

Do not duplicate database schema, HTTP endpoint semantics, or implementation order here. Use [Database](/versions/v0/developer/database), [API development](/versions/v0/developer/api), and [Development instructions](/versions/v0/developer/development-instructions) as their canonical sources.

## RFC modules

Policy and Workflow package designs are deliberately isolated from the defined foundation. Their proposed public ports and persistence are documented on [Policy (RFC)](/versions/v0/developer/policy) and [Workflow (RFC)](/versions/v0/developer/workflow); do not create them as delivered capabilities merely because their target layout is documented.
