---
title: Stack
description: Group React nodes in a Page component tree.
---

import { TypeTable } from 'fumadocs-ui/components/type-table';

Use `Stack` to group text and nested components while preserving their source order. Component
names are case-sensitive, so `stack` is invalid.

```yaml
component: Stack
props:
  data-component-id: hero
children:
  - component: Typography
    props:
      variant: h1
    children: Hello World
  - component: Typography
    props:
      variant: p
    children: '{{ Trans "pages.index.introduction" }}'
```

For example, `children` can be a string, a component node, or an ordered list of component nodes
and strings. A list preserves source order.

## Validation

A `Stack` node is invalid when:

- `component` does not exactly match `Stack`.
- A `props` field does not begin with `data-`.
- `children` cannot be represented as a ReactNode by the Page schema.
