---
title: Typography
description: Render string content with a semantic text variant.
---

Use `Typography` to render a text string with a heading, paragraph, or inline text variant.
Component names are case-sensitive, so `typography` is invalid.

```yaml
component: Typography
props:
  variant: h1
children: Hello World
```

## Fields

| Field           | Rule                                                    |
| --------------- | ------------------------------------------------------- |
| `component`     | Must be `Typography`.                                   |
| `props.variant` | Required: `h1`–`h6`, `span`, or `p`.                    |
| `children`      | Required string. A `Trans` expression is also a string. |

`Typography.children` cannot contain nested component nodes.

| Content purpose | Allowed variants  |
| --------------- | ----------------- |
| Heading         | `h1` through `h6` |
| Paragraph       | `p`               |
| Inline text     | `span`            |

## Validation

A `Typography` node is invalid when:

- `component` does not exactly match `Typography`.
- `props.variant` is outside `h1`–`h6`, `span`, and `p`.
- `children` is not a string.
