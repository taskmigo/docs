---
title: Typography
description: Render string content with a semantic text variant.
---

import { TypeTable } from 'fumadocs-ui/components/type-table';

Use `Typography` to render a text string with a heading, paragraph, or inline text variant.

```yaml
component: Typography
props:
  variant: h1
children: Hello World
```

`Typography.children` cannot contain nested component nodes.

| Content purpose | Allowed variants  |
| --------------- | ----------------- |
| Heading         | `h1` through `h6` |
| Paragraph       | `p`               |
| Inline text     | `span`            |
